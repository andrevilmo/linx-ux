[ ] 5. Publish-ToIis.ps1 -FrameworkRoot 'C:\Linx Program Files\Linx Framework 6.0.0'

[ ] 2. Pack 2 on a clone + MSBuild Linx.Framework.BV.csproj /p:Configuration=Release
[ ] 3. Copy bin\Release\Linx.Framework.BV.dll into 3-publish-iis\Service\bin\
[ ] 4. PowerShell as Administrator
[ ] 5. Publish-ToIis.ps1 -FrameworkRoot 'C:\Linx Program Files\Linx Framework 6.0.0'
